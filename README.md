## Hi, I'm Jalal 👋

**Backend web developer and IT support specialist.** I build database-driven web
applications in Python and Django, and I've spent 13+ years on the technical side of a
web hosting business.

That second part matters more than it sounds. Living with production issues every day —
servers, DNS, deployments, billing systems, customers who are annoyed and right to be —
changes how you write code. You think harder about failure states, logging, and the
person who has to support the thing at 9am on a Monday.
